# Haven gallery concepts

These seven WebP files are AI-generated concepts for the fictional Haven Hotel,
created with the built-in image-generation tool on 2026-11-12. They do not depict
an actual property. The gallery identifies them in alt text, the photo disclosure
and the full-screen viewer. The existing local Deluxe King and bathroom concepts
complete the nine-photo sample sequence.

The sample sequence is used only while `isDemo` is true and the gallery still
matches the original four-entry seed exactly. Any gallery edit or removal opts
out; client publications use the saved photos. Category and supporting-caption
fields are optional, backward-compatible fields in the existing versioned CMS
JSON document. No database migration or publication was made for these assets.

Prompts used (all requested one landscape, photorealistic 16:9 image, without UI,
collages or watermarks):

- `exterior.webp`: Front facade and main arrival of a fictional boutique city
  hotel in Ermita, Manila. Warm ivory stone, vertical dark timber fins, bronze
  canopy with a discreet HAVEN sign, tropical planting, realistic city context,
  late-afternoon sunlight, architectural verticals straight.
- `entrance.webp`: Close view of the same entrance using the facade as a reference;
  preserve ivory stone, bronze canopy/sign, palms, glass doors and welcoming light.
- `evening.webp`: The same facade at blue hour, preserving structure and material,
  with warm windows and arrival lighting against a navy twilight sky.
- `courtyard.webp`: Landscaped private courtyard in the same material language,
  with tropical planting, stone paths, a small circular fountain and shaded seats.
- `pool.webp`: Small courtyard pool, turquoise water, ivory hotel walls, timber
  windows, tropical planting, four loungers and neutral parasols in afternoon light.
- `lobby.webp`: Ivory stone floor, timber reception, curved neutral sofas, white
  lilies on a round stone table, tall garden-facing windows and subtle brass lamps.
- `dining.webp`: The Haven Table restaurant, cane/timber chairs, ivory linen,
  glasses and white plates, bronze windows facing the courtyard and warm lamps.

The facade image served as the architectural/material reference for the other six
images. The original generated PNGs remain in the user's Codex generated-images
directory. Project copies were encoded with Sharp at WebP quality 85.
