# 2026-09-08 - Session 04 — Manager Reservations Oversight & Exception Monitoring Workspace

Redesigned **Manager → Reservations** from a read-only copy of the Front Desk queue into a
derived, advisory oversight workspace. Zero business-rule / RBAC / migration changes. All four
quality gates green (typecheck, lint 0 errors, 648/648 tests, build).

## What shipped

- **`lib/manager-attention.ts`** (new) — pure, client-importable derivation of operational
  issues (like `lib/staff-duty.ts`): overdue checkout (high) → room-readiness family (high,
  authoritative room state only) → arrival unresolved (warning, "possible no-show" is advisory
  text — never a status change) → manager review required → room assignment pending (arrival
  today) → outstanding balance / refund pending → transportation unreviewed → escalated guest
  request. Terminal statuses produce nothing. `byAttentionThenStay(today)` sorts the attention
  queue worst-first. Imports nothing server-only.
- **`lib/staff-data.ts`** — `listForRole("reservations","manager")` decoration via one batched
  `Promise.all` (rooms, blocking maintenance, pending approvals, active transport, unresolved
  refunds, escalated guest requests) — no N+1. `getStaffReservation` adds
  `checked_in_at/checked_out_at` to the detail select plus gated lookups:
  `transportation_requests` (canViewTransportation), `manager_approval_requests`
  (manager/owner), and the `checkout_cleaning` turnover task — all in the existing
  `Promise.all`. Demo mode has a `decorateManagerAttentionDemo` twin.
- **`components/manager/manager-reservations-panel.tsx`** (new) — the workspace: manager
  subtitle, filter chips **Attention Required** (default, derived count) → Arrivals Today →
  Departures Today → In-House → Upcoming → All → Closed, 8-column table with an
  **Operational Issue** badge (top issue + `title` = all issues), unassigned-today visually
  distinct, View + Review Exception only. Mobile card twin ≤720px (`.mr-*`, approval-card
  pattern).
- **`manager-dashboard-client.tsx`** — renders the panel for
  `section==="reservations" && user.role==="manager"` (Front Desk queue untouched);
  `reviewReservationException` = close modal → prefill approvals search → jump to approvals
  section (routes through the existing review workflow, no new mutation surface);
  `ReservationDetailModal` gains (oversight-gated) header arrival/departure badges, a
  **ReservationLifecycle** stepper (real timestamps only — "Confirmed" is status-gated, no
  `confirmed_at` column exists), Room & Readiness, Transportation, and Manager Approvals
  groups with a Review Exception button.
- RBAC unchanged: all modal action buttons stay behind `canManage={operational}` /
  `canFinancial={cashHandling}` flags, which are false for manager. `lib/permissions.ts`
  untouched.
