# Shared Download menus

Standardized existing export and print controls with one shared Download menu
using HavenSelect. Preserved Finance CSV/Excel/PDF, receipt PDF/PNG/print,
guest QR PNG, and browser print for staff reports, in-house register and
room placard. Added mobile inline expansion and layered Escape behavior.

Authenticated Edge verified real Finance and guest files on a synthetic local
stack. Four browser-rendered print PDFs were independently read back. Report
print issued no submission request. 2,337 full tests and 67 targeted tests,
build and touched-file lint passed. See the
[acceptance register](../../../../docs/qa/enterprise-architecture-acceptance-2026-11-04.md).
No schema change or hosted rollout.
