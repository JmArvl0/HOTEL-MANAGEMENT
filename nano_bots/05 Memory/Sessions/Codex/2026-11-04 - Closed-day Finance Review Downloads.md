# Closed-day Finance review downloads

User requested CSV, Excel and PDF through one modern dropdown. Added it to
Accounting's closed-day history using HavenSelect and existing surface tokens.
Mobile options expand below the saved totals. The new Accounting-only route
reads a saved night audit, creates a versioned review batch, and logs issuance
without creating an accounting posting. All three formats use the same
seven totals. No schema or release change.

Authenticated Edge at 1440, 820 and 390px, plus mobile dark mode, covered the
dropdown, file download, focus, role denial and retry. Independent readers and
renders verified the real downloaded files. One real closed snapshot persisted
in the disposable fixture. Finance-approved line mapping, real import,
acknowledgment and reconciliation remain pending. See the
[acceptance register](../../../../docs/qa/enterprise-architecture-acceptance-2026-11-04.md).
