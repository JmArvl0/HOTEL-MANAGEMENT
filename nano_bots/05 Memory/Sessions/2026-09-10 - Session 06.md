# 2026-09-10 — Session 06: Collapsible sidebar groups — Owner & Admin clients

## Work completed

Extension of the Session 04 sidebar work to the two roles that render their own clients on
`/manager_dashboard` (per SYSTEM.md §7.9): **OwnerDashboardClient** and **AdminDashboardClient**
now use the same collapsible category sidebar as ManagerDashboardClient. The customer portal
navbar was NOT touched (explicit user constraint).

- `components/owner/owner-dashboard-client.tsx` — new exported `NAV_GROUPS`:
  **Executive** (overview, operations, financial, departments) · **Governance** (admins, roles,
  policy, exceptions, audit, security, reports) · **Catalog** (room_types, transport_services,
  transportation). Replaced the flat `Executive` caption + 14-button nav with group headers
  (`aria-expanded`/`aria-controls`, `ChevronRight` rotation) and the `grid-template-rows:0fr→1fr`
  collapse. Open/closed state persists in `localStorage["haven-owner-sidebar-groups"]`
  (`Record<string, boolean>`); the active module's category is forced open by derivation
  (`(openGroups[id] ?? false) || group.sections.includes(section)`), so the Overview
  "Review exceptions" button auto-opens Governance with no coupling.
- `components/admin/admin-dashboard-client.tsx` — same pattern, `NAV_GROUPS`:
  **Workspace** (overview) · **Accounts** (users, roles) · **Configuration** (rooms, room_types,
  transport_services, policy) · **Governance** (audit, security, reports). Persistence in
  `localStorage["haven-admin-sidebar-groups"]`. The Overview "Manage users" cross-link gets
  auto-open the same way.
- Grouping is presentational in both: the `nav` tuples, section types, all fetch/action logic,
  and the governance-test-pinned label strings are byte-unchanged. Owner/Admin are single-role
  clients with no RBAC nav filtering, so no auto-hide logic was needed there.
- No CSS changes: the Session 04 rules in `app/manager-dashboard-theme.css` are scoped to
  `.app-shell .sidebar`, which all three clients share (including the collapsed-rail and mobile
  drawer resets and the `width:calc(100% - 8px)` overflow fix).
- `components/staff-sidebar-groups.test.tsx` (new) — pins both IAs: every module in exactly one
  non-empty category, union equals the full module list (owner 14, admin 10).
- `SYSTEM.md` §7.10 — added a paragraph documenting the grouped sidebar, category names, and the
  two new localStorage keys.
