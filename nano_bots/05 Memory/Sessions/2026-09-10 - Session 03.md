# 2026-09-10 - Session 03 — /booking/search modal fix, Go back button, landing hero/wash composited

## Delivered

1. **View-details modal blinking (root cause fix)** — `.available-room:hover{transform:translateY(-3px)}`
   made the hovered card the containing block for the modal's `position:fixed`, so the dialog
   repositioned per hover-frame. Fix: opt-in `portal` prop on the shared `components/ui/Modal.tsx`
   (`createPortal` to `document.body`); `RoomDetailsButton` passes it. Portal is opt-in because
   dashboard modals rely on in-place mounting (`.app-shell .modal-content` rules in
   manager-dashboard-theme.css). Hover lift intentionally kept.
2. **"Go back" pill under breadcrumbs** — new `components/booking/back-button.tsx`
   (`router.back()` with same-origin referrer guard, `/` fallback); rendered on `/booking/search`.
3. **Landing hero image/wash scroll desync** — GSAP scaled only `.coast-hero-image` while
   `.coast-hero-wash` stayed static (image 1558×711 vs wash 1425×650 at scrollY 400), plus a stale
   scale-1.05-at-top bug (scrub `gsap.to` captured its start value before the load timeline
   finished). Fix (impeccable Option A): new `.coast-hero-media` wrapper (absolute inset:0,
   z-index:-3, transform-origin center) owning geometry + the GSAP scale; image/wash fill it
   (z-indexes dropped — wrapper's stacking context + DOM order); `.coast-hero` keeps
   `overflow:hidden` as the fixed clip. Scrub is now `gsap.fromTo(media,{scale:1},{scale:1.12,
   immediateRender:false})`. GSAP stays sole transform owner in `landing-motion.tsx`.
   **Featured Stays**: audited at 1440/1366/1024/1000/768/390 — no defect (stretch grid +
   `margin-top:auto` price pinning; grid reveals as one unit, 0 divergent frames). No change made.

## Lessons

- Synthetic `.click()` never sets `:hover` — use real CDP hover/click tools to reproduce hover bugs.
- `gsap.to` with `scrub` created while another tween animates the same property captures a stale
  start value; use `fromTo` + `immediateRender:false`.
- Scroll-anchoring can leave `scrollY` at ~11px after `scrollIntoView` — verify `scrollY===0`
  before reading "at top" transforms.
